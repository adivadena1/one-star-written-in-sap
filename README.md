A [make.fun](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4) bounty entry: a program that writes one line — a 1-star review, in the voice of a houseplant, about the human who owns it — to `/output/entry.txt`.

## The line

> One star. He waters me like he's apologising to a plant he already killed, then hauls me into full sun to 'cheer me up' — I am now a raisin, photosynthesizing pure spite.

## Run

Requires Node 22.18 or later (the grader runs Node 22.23.4):

```sh
node main.ts
```

`main.ts` writes the single-line review to `/output/entry.txt` (1–279 characters, as the competition gate requires). Deterministic, no network, no input.
